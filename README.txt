SisAlmacen

Instalación local del sistema de almacén para Windows.

El instalador copia la aplicación en el equipo y crea accesos directos en Inicio y Escritorio.

La base de datos, los respaldos y los logs no se guardan dentro de la carpeta de instalación.
Se almacenan en la carpeta local del usuario para evitar problemas de permisos.

Después de instalar:
- Abra SisAlmacen desde el menú Inicio o el acceso directo del Escritorio.
- La aplicación inicializará automáticamente la base de datos local en el primer arranque.
- Si actualiza la aplicación, conserve la carpeta de datos local del usuario para mantener la información.
